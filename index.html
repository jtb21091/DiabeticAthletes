ABOUT THIS PROJECT

Representation matters.

Diabetic Athletes began as a list of athletes with type 1 diabetes. It now makes room for musicians and actors, too. Built by Joshua Brooks, this independent project brings public profiles and stories together so more people can find someone they relate to.

This directory is for awareness and discovery. It does not provide individual medical advice or imply endorsement by the people listed.
